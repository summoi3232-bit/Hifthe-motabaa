# متابعة الحفظ والتثبيت والمراجعة (نسخة موحّدة)

تطبيق PWA واحد يجمع «متابعة الحفظ» و«مراحل الحفظ»، بلا أدوات بناء.

## مسار المقطع

1. **الحفظ العقلي**: 9 تكرارات (3 استماعات مركّزة، 3 نظرًا، 3 عن ظهر قلب).
2. **الحفظ اللساني**: 30 تكرارًا فأكثر (الهدف يُعدَّل من ⚙).
3. **المراجعة المتباعدة (SM-2)**: الأولى بعد 3 أيام والثانية بعد 7، ثم الفاصل = السابق × معامل سهولة خاص بكل مقطع (يبدأ 2.5، أدناه 1.3، وأقصى فاصل 90 يومًا).
   - أربعة تقييمات: **ضعيفة** (تعيد المقطع للحفظ اللساني وتُنقص المعامل كثيرًا) / **متردد** (يبقى في مستواه ويُنقص المعامل) / **متقنة** (ينتقل للتالي) / **سهلة** (ينتقل ويزيد المعامل). وتحت كل زر الفاصل المتوقع.
   - يتثبّت المقطع حين يبلغ فاصله القادم 30 يومًا فأكثر (`GRAD`)، ومن نسيه 3 مرات تظهر عليه شارة «متعثّر».
   - بطاقة «توقّع المراجعات» (7 أيام) في تبويب المراجعة، وترتيب المستحق اليوم بالأكثر تأخرًا أولًا.
   - ثوابت الجدولة في أعلى `index.html`: `FIX` و`EFMIN` و`GRAD` و`MAXI`.
   - المقاطع القديمة (بلا `ef`) تعمل كما هي: يُستنتج مستواها وفاصلها من `lv`، ولا تلزم إعادة استيراد.
4. **الورد الأسبوعي**: تدخله السورة تلقائيًا إذا اكتملت آياتها وثُبّتت كل مقاطعها، أو تنقلها يدويًا. الفاصل 7 أيام افتراضيًا، ويمكن من ⚙ رفع أقصى فاصل (10 / 14 / 21 / 30) فيتّسع تدريجيًا بحسب معامل سهولة السورة.

مع: غفلة وتنبيهات، مواضع التردد لكل سورة، مؤقت الجلسة، سلسلة الأيام وإحصاء الأسبوع، نسخ احتياطي.

## الترحيل من التطبيقين القديمين

- إن نُشر هذا التطبيق على **نفس الرابط** القديم، تُنقل البيانات تلقائيًا عند أول فتح.
- وإلا: صدّر نسخة احتياطية من القديم، ثم «استيراد» هنا (يقبل صيغة التطبيقين).
- مقاطع «متابعة الحفظ» القديمة التي لم يُكتب فيها رقم الآيات تُحفظ كنص ولا تُحتسب في تغطية السورة.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | التطبيق كاملًا |
| `sw.js` | العمل دون اتصال + استقبال الإشعارات |
| `manifest.webmanifest`, `icons/` | التثبيت على الهاتف |
| `netlify.toml`, `package.json`, `netlify/functions/` | النشر ودوال الإشعار المضمون |

## النشر (Netlify)

ارفع المجلد إلى GitHub ثم Add new site ← Import from Git (السحب والإفلات لا يثبّت حزم الدوال). التطبيق يعمل دون الإشعار المضمون؛ لتفعيله:

1. `npx web-push generate-vapid-keys`
2. في Netlify ← Environment variables: `VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY` و`VAPID_SUBJECT` (مثل `mailto:you@example.com`)
3. أعد النشر، ثم من الهاتف: ⚙ ← «تفعيل الإشعار المضمون» (على آيفون أضف التطبيق للشاشة الرئيسية أولًا).

## التحديث

عدّل الملفات ثم غيّر `VERSION` في `sw.js` ليتحدّث الكاش.
